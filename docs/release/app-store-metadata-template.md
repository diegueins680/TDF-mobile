## Description

`TDF Records is a mobile operations workspace for internal teams and authorized partners.`

`Use the app to manage parties and bookings, review pipeline stages, browse upcoming events, exchange vCards, discover nearby venues, and keep inventory data current while on the move.`

`Key capabilities include:`

- `Parties and CRM access`
- `Bookings and pipeline tracking`
- `Event discovery and saved events`
- `vCard QR sharing and social graph tools`
- `Venue exploration with optional location access`
- `Inventory updates with optional camera and photo library access`

`Access to protected features requires organization-provided credentials.`
